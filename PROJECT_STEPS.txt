DZ-TS-FINAL

1. Создан React-проект с TypeScript.
2. Подключены React Bootstrap, Bootstrap, React Router и Sass.
3. В constants/cities.ts сохранены 6 городов из задания.
4. Для каждой карточки выполняются два запроса:
   - поиск координат по названию города;
   - получение текущей погоды по координатам.
5. Карточки выводятся через общий WeatherCard и Bootstrap Grid.
   На больших экранах — 3 в ряд, на средних — 2, на мобильных — 1.
6. Во время загрузки используется Bootstrap Spinner.
7. Кнопка "Смотреть прогноз" передаёт город, latitude и longitude
   на страницу /weather/:city.
8. Страница прогноза получает через API 7 дней:
   дату, минимальную температуру, максимальную температуру и weather code.
9. Weather code расшифровывается общей функцией из utils/weather.ts.
10. Формат даты вынесен в utils/date.ts.
11. Общий useRequest используется и на главной, и на странице прогноза.
12. Реализован AutocompleteInput:
   - запрос к Geocoding API после ввода;
   - небольшая debounce-задержка;
   - Form.Control и ListGroup из React Bootstrap;
   - выбор варианта открывает прогноз выбранного города.
13. Ошибки fetch обрабатываются и выводятся через Alert,
   поэтому необработанных Promise-ошибок в консоли быть не должно.
14. Для GitHub Pages используется HashRouter.
15. Для публикации:
   npm run deploy
